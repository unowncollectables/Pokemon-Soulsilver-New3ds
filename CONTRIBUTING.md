# Contributing

Thanks for your interest in helping with this project.

## Before you contribute

- Read the README and project status first
- Check open issues and current roadmap discussions
- Keep your changes focused and testable
- Do not commit ROMs, Nintendo-owned game assets, or extracted copyrighted content

## Development expectations

- Keep code and documentation clear and maintainable
- Prefer small, reviewable commits
- Document any build or runtime changes
- Cite upstream sources or references when you borrow logic or structure

## How to contribute

1. Fork the repository
2. Create a topic branch for your work
3. Make targeted changes
4. Validate locally if possible
5. Open a pull request with a clear summary

## Reporting issues

When opening an issue, include:

- what you expected
- what happened instead
- exact build or runtime steps
- device and environment information
- any relevant logs or screenshots

## Code style

Follow the conventions already used in the project. If the codebase is still being established, favor clarity and consistency over cleverness.

## Legal and safety

This project is a homebrew decompilation/porting effort. Do not add copyrighted game files or assets to the repository.
