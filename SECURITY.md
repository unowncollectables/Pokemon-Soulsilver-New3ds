# Security Policy

## Supported versions

This project is still in active development. Because the repo may change quickly, security issues should be treated as important even when the project is not yet in a stable release phase.

## Reporting a vulnerability

Please do not open a public GitHub issue for security-sensitive problems.

Instead, report the issue privately through a secure channel or by contacting the repository maintainer directly.

Please include:

- a clear description of the issue
- affected files, versions, or commits
- reproduction steps if available
- estimated impact and severity
- any suggested fix or mitigation

## Response expectations

We will do our best to acknowledge valid reports quickly and assess the issue as soon as possible. Since this is a small active project, response times may vary depending on workload and available time.

## Responsible disclosure

We ask that you avoid public disclosure until the issue has been reviewed and a fix or mitigation has been prepared.

Thanks for helping keep this project safe for contributors and users.
